# Voxcalibur 1.0.0

Première version indépendante, issue de Transcrinator 1.3.17.

- Nouveau nom, logo fourni, icône Windows et accueil ambre/noir.
- Dictée locale Parakeet Ultra et Silero VAD ; moteurs CPU, Vulkan et CUDA inclus.
- Aucun composant de la suite Ergonatus requis.
- Profils, raccourcis et entrées Windows propres à Voxcalibur.
- Versions installable et portable complètes, hors ligne.
- 258 tests automatisés réussis.
- Transcription réelle vérifiée avec l’exécutable embarqué sur CPU et CUDA.

Portable : décompresser entièrement puis lancer Voxcalibur.exe.
Installation : décompresser l'archive, garder les quatre fichiers ensemble et lancer Installer-Voxcalibur.exe.

Les deux archives complètes incluent les mêmes modèles et runtimes. Le mode portable écrit ses préférences dans le profil utilisateur. Windows 10/11 x64 ; microphone requis ; 16 Go de RAM conseillés. Le démarrage avec Windows se règle dans les préférences.
